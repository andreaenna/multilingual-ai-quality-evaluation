# multilingual-ai-quality-evaluation
Evaluation benchmark for multilingual large language models.

## Overview

This project investigates the quality of multilingual responses generated by Large Language Models (LLMs).

The evaluation focuses on four languages:

- English
- Italian
- Spanish
- Portuguese

The project applies structured human evaluation methods to assess:

- Accuracy
- Fluency
- Instruction following
- Cultural appropriateness
- Hallucinations

The goal is to demonstrate a reproducible methodology for multilingual AI quality assessment.

---

## Objectives

- Build a multilingual evaluation dataset.
- Design annotation guidelines.
- Evaluate AI responses using a consistent scoring framework.
- Analyse strengths and weaknesses across languages.
- Publish the methodology openly on GitHub.
